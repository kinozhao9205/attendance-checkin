# HEYDAY 海外员工打卡页

海外员工人脸定位打卡页（PWA，可安装到主屏幕、支持离线打开）。

**打卡入口**：浏览器直接打开 / Telegram Web App / 钉钉内免登 / 自助注册。

- 页面（GitHub Pages，海外访问）：https://kinozhao9205.github.io/attendance-checkin/checkin.html
- API（国内阿里云，已备案域名）：https://www.bydtyr.com/att-api/（配置见 `assets/att-config.js`）

> 本仓库只含静态打卡页；后端服务与数据库在国内服务器，源码不在本仓库。
